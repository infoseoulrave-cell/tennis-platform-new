# 라켓 고품질 파라메트릭 렌더 설계

작성일: 2026-07-31
선행 문서: `2026-07-31-beginner-structure-design.md` (도식 1차)

## 배경

도식 1차에서 사진 위 CSS mask 덧칠을 걷어내고 스펙 기반 도식으로 교체했다.
정확도 문제는 사라졌지만 그림이 단순하다. 실제 라켓 디자인에 가까운 품질로 올린다.

## 절대 조건

**손으로 찍은 좌표 파일을 다시 만들지 않는다.** 이전 실패(`racket-customizer-mask-geometry.ts` 327KB)
의 원인은 라켓마다 사람이 좌표를 찍어야 했다는 점이다. 모든 값은 셋 중 하나여야 한다.

1. 이미 DB에 있는 값
2. 사진에서 자동 추출한 값 (재실행하면 같은 결과)
3. 브랜드 패밀리 단위 큐레이션 (모델 수와 무관하게 개수가 고정)

## 사전 확인된 사실

- Tennis Warehouse 이미지는 **서버에서 정상 응답**한다 (200 / image/jpeg / 약 42KB).
  브라우저에서만 비는 것은 별개 문제다 — 범위 밖으로 기록한다.
- `beamWidth` 는 이미 DB에 있고 (`23/26/23mm` 형태) 현재 렌더에 쓰이지 않는다.

## Layer 1 — 형상 파라미터

| 값 | 출처 | 개수 |
|---|---|---|
| 헤드 면적 | `headSize` | 기존 |
| 스트링 가닥 수 | `pattern` | 기존 |
| 빔 두께·테이퍼 | `beamWidth` | 기존 (미사용 → 사용) |
| 헤드 형태 | 브랜드 패밀리 테이블 | **약 10개** |

헤드 형상은 모델이 아니라 브랜드 패밀리 속성이다. Yonex는 아이소메트릭(각진 형),
Head Gravity·Prestige는 둥근 형, Babolat Pure Aero는 티어드롭이다.
따라서 패밀리 테이블 약 10줄이 54종을 덮고, 신규 모델은 브랜드만 알면 자동으로 붙는다.

형상은 초타원(superellipse)으로 표현한다.

```
|x/a|^n + |y/b|^n = 1
```

- `n = 2` 이면 일반 타원 (기본형)
- `n > 2` 이면 모서리가 각져 Yonex 아이소메트릭에 가까워진다
- `aspect` 로 세로/가로 비를 조절해 둥근 형을 만든다
- `topBias` 로 위쪽 반경을 키워 티어드롭을 만든다

스트링 끝점도 같은 초타원에서 구한다. 메인이 `x` 에 있을 때
`y = b * (1 - |x/a|^n)^(1/n)` 이므로 폐형식으로 계산된다.

## Layer 2 — 컬러웨이 (사진에서 자동 추출)

오프라인 스크립트가 제품 사진을 받아 대표색을 뽑아
`src/data/racket-colorways.generated.ts` 를 생성한다.

- 흰 배경, 거의 무채색인 스트링, 어두운 그립 영역을 제외한 화소만 사용한다
- 색 히스토그램을 양자화해 빈도 상위 2~3개 클러스터를 고른다
- 같은 입력에 같은 출력을 낸다 (결정적)
- 이미지 디코딩용 `sharp` 는 **devDependency 로만** 추가한다 — 런타임 번들에 들어가지 않는다

추출에 실패하면 그 라켓은 중립 프레임 색으로 떨어진다. 지어내지 않는다.

## Layer 3 — 렌더러

품질을 실제로 올리는 요소는 넷이다.

1. **스트링 교차 위빙** — 교차점마다 메인과 크로스의 상하를 번갈아 그린다.
   지금은 선이 그대로 겹쳐 격자처럼 보인다. 구현은 전체 메인 → 전체 크로스 →
   `(i + j) % 2 === 0` 인 교차점에서 메인의 짧은 조각을 위에 덧그리는 순서다.
2. **빔 테이퍼** — 후프를 고정 두께 stroke 가 아니라 외곽선과 내곽선 사이를 채운
   path 로 그리고, 내곽 반경을 각도에 따라 바꿔 실제 빔 프로파일을 반영한다.
3. **그로밋 스트립과 범퍼가드** — 프레임 안쪽 띠와 상단 보호대.
4. **재질 음영** — 비대칭 조명 그라디언트와 미세한 드롭섀도.

## 정직성 가드레일

`.impeccable.md` 의 "fake precision 회피" 원칙을 우선한다.

- 브랜드 로고와 문양 그래픽은 **재현하지 않는다.** 재현하면 위조에 가까워진다.
- 화면에 제품 사진이 아니라 렌더라는 표기를 유지한다.
- 스펙이 없으면 그리지 않는다 (현행 fail-closed 유지).

## 검증

- 위빙: 교차점 개수와 상하 교대가 패턴과 일치한다
- 형상: 초타원 위의 점만 나오고 캔버스를 벗어나지 않는다
- 빔: `beamWidth` 파싱이 `23/26/23mm` 및 결측을 모두 처리한다
- 컬러웨이: 같은 입력에 같은 출력 (결정적)
- 기존 181개 회귀 없음, typecheck / lint / build 통과
