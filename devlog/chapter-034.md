# Chapter 34 — 공개 페이지 사이트맵과 robots 안내

운영 사이트의 `/robots.txt`와 `/sitemap.xml`이 404로 응답하고,
저장소에도 생성 경로가 없던 상태를 보완한다. Next.js 메타데이터 라우트로
주요 공개 페이지 목록과 사이트맵 위치를 제공한다.

## 변경

- `src/app/sitemap.ts`에서 `MetadataRoute.Sitemap`을 사용해
  `https://racketlab.kr`의 고정 공개 경로 18개를 열거한다.
- 홈, 라켓·스트링·의류/용품 목록, 가이드 목록과 5개 가이드,
  상식·선수·업데이트·소개·매장 페이지, 국내외 제휴·광고 안내를 포함한다.
- `lastModified`, 변경 주기와 우선순위는 임의로 설정하지 않는다.
- `src/app/robots.ts`는 `MetadataRoute.Robots`로 기본 크롤링 허용과
  canonical 사이트맵 URL을 안내한다. 기존 페이지의 robots 메타데이터와
  접근 제어는 변경하지 않는다.

## 범위와 한계

이 사이트맵은 주요 고정 URL의 부분 목록이다. 라켓 상세·커스터마이저
전체 목록을 조회하는 데이터 피드나 API는 추가하지 않았다. 관리자·API,
개인 결과·위시리스트, 필터·정렬 등 쿼리 변형과 레거시 리다이렉트 경로는
열거하지 않는다. 진단 입력 흐름과 선택한 라켓에 의존하는 비교 화면도
이번 목록에서 제외한다. 목록에 없다는 이유로 해당 페이지의 크롤링이나
색인을 차단하는 정책을 추가한 것은 아니다.

검색엔진의 수집·색인·검색 노출이나 방문·구매 성과는 아직 확인하지 않았다.

## 검증 상태

로컬 테스트 304개, typecheck, lint, build를 통과했다. 빌드 산출물의
XML을 파싱해 canonical URL 18개가 중복 없이 포함되고 의류 가이드와
용품 페이지가 포함됨을 확인했다. robots 산출물도 사이트맵 위치를
정확히 안내한다. 목록의 운영 URL 18개는 HEAD 요청에 모두 200으로
응답했고 리다이렉트가 없었다. 독립 코드 검토에서 P1/P2 문제는 없었다.

CI·프리뷰와 운영의 새 메타데이터 경로 응답은 배포 실행 기록에 별도로
남긴다. 이 검증은 검색엔진의 실제 수집·색인 여부를 확인한 결과가 아니다.
