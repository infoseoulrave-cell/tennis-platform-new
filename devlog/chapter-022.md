# Chapter 22 — 홈 크리틱 잔여 3건: 면책 1회 · 이모지 제거 · 섹션 질감 차별화

### 목표
Ch.20 크리틱에서 이월된 세 건을 닫는다. 원칙은 Ch.18과 동일 — 장식을 걷어내고
정보 구조로 질감을 만든다. Omega 시그니처(백색/회색, 라임 절제)는 유지.

### 완료 내용
- **면책 문구 1회화**: 카드마다 반복되던 `equipment.disclosure`를 홈 쇼케이스
  카드 9장·/players 카드 21장 전부에서 제거. 홈은 레일 아래 푸트노트 1회
  (같은 데이터 사용, parity 테스트의 `equipment.disclosure` 검증 유지),
  /players는 기존 페이지 헤더 면책이 담당.
- **이모지 제거**: 지식 카드(🐄⚖️🔬🎭💪)·뉴스 카테고리(🆕💡) 데이터 필드 삭제,
  국기 이모지 → IOC 3자리 코드(`src/lib/country-code.ts`), 히어로 ⚡ → 기존
  기하 글리프 세트와 결이 맞는 ▲, 스트링 가이드 👍👎 → +/− (sr-only로
  "장점/주의" 병기).
- **섹션 질감 차별화**: 네 섹션이 같은 틀(헤더+백색 카드 블록)이던 것을
  콘텐츠 형식대로 갈랐다.
  - POPULAR — 순위 리스트 (기존 유지, 이미 고유)
  - UPDATES — 카테고리 칩 상자 제거, 인라인 라벨의 날짜 로그로
  - PRO PLAYERS — 세로 그리드(홈 스크롤의 절반) → **가로 스냅 레일**.
    잘린 다음 카드가 스크롤 어포던스. 홈 세로 길이 대폭 축소.
  - KNOWLEDGE — 카드 상자·섀도 제거, 항목당 진한 상단 룰의 에디토리얼 인덱스
