# Chapter 31 — 광고 포스터 구도의 홈 캠페인

사용자가 제공한 Kive 레퍼런스의 큰 단일 라켓, 입체적인 조명, 대형 문구를
홈 배너에 반영했다. 이전의 흰 제품 사진판·둥근 카드·점수 칩을 걷어내고
전체폭 캠페인 이미지와 웹 타이포, 얇은 하단 제품 정보 행으로 바꿨다.

## 구현

- Babolat Pure Aero, HEAD Speed MP, Yonex VCORE의 실제 제품 사진을 참고해
  1536×1024 AI 캠페인 이미지 3개를 생성했다. 각 WebP는 120–142KB다.
- 실제 JPG와 출처는 그대로 보존하고 campaignImageUrl을 별도로 사용한다.
  공개 화면에 AI 연출 비주얼과 실제 제품 사진 링크를 함께 표시한다.
- 문구는 이미지에 넣지 않고 웹 텍스트로 렌더한다. 320px에서 긴
  YOUR FLOW.가 잘리지 않도록 모바일 크기를 조절했다.
- 고정 h1과 진단 입구는 데스크톱 캠페인 아래에 한 번 렌더한다.
  모바일의 캠페인 → TOP 5 → 진단 안내 순서는 유지한다.
- 기존 canonical 점수·스펙, 광고 조건·계측, 포커스·호버 일시정지,
  수동 이동 및 reduced-motion 제어를 유지했다.
- HEAD 문구에서 특정 선수가 해당 시판 모델을 직접 쓴다는 암시를 제거했다.

## 제작 기록

Higgsfield Soul 요청은 크레딧 부족 HTTP 403으로 실패했다. 작업 ID가
발급되지 않았으며 충전하지 않았다. 사용자에게 알린 뒤 내장 이미지 생성으로
이어갔다. 원본 경로·정확한 프롬프트·참고 파일은
[hero-campaign-imagery.md](../docs/hero-campaign-imagery.md)에 기록했다.

## 검증

- npm test: 298/298 통과.
- npm run typecheck, npm run lint, npm run build, git diff --check 통과.
- 인앱 브라우저에서 데스크톱 이미지 로딩, 슬라이드 이동, h1 한 개,
  canonical 상세 링크·점수·출처를 확인했다.
- 390px/320px 같은 출처 iframe으로 모바일 구도를 확인했다.
  실제 휴대폰 하드웨어 검증은 아니다. 임시 QA 파일은 배포 전에 삭제했다.
- 독립 리뷰의 긴 문구 잘림 우려를 수정했고 확인된 P1/P2는 없다.

CI와 Vercel Preview 확인 뒤 병합하며, 실제 배포 식별자와 최종 확인은
운영 실행 기록에 남긴다. 이 변경으로 판매·제휴 계약이나 광고 수익이 발생한
것으로 집계하지 않는다.
