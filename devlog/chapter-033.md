# Chapter 33 — 테니스 스커트·원피스 구매 가이드

의류 컬렉션을 찾기 전에 이너 구조, 공 수납, 사이즈표와 제품 기장,
색상·사이즈별 주문 가능 여부를 확인할 수 있도록 `/guide/tennis-apparel`을
추가했다. 가이드 목록과 `/gear`에서 읽고 스커트·원피스를 포함한 공식몰
컬렉션으로 이어갈 수 있다.

## 변경

- 서버 정적 기사에 제목·설명·canonical 메타데이터를 제공한다.
- 일반 포켓과 공 수납 방식, 신체 치수와 제품 실측을 구분하고 설명
  미확인을 기능 부재로 판단하지 않도록 안내한다.
- Nike 수납 예시와 Lacoste 공식 신체 사이즈표를 출처로 연결한다.
  직접 열기가 보안 차단된 Adidas 도움말은 최종 출처에서 제외했다.
- 상품 가격·재고·추천·제휴 지위나 실적을 표시하지 않는다.
- 본문 16px, 한국어 어절 줄바꿈과 제목 균형, 네이티브 링크·포커스
  표시를 사용한다. 새 의존성·클라이언트 상태·이미지는 추가하지 않았다.

## 검증

- 기존 테스트 304/304, typecheck, lint, build, diff-check 통과.
- 독립 React·콘텐츠 검토에서 새 P1/P2 없음.
- 로컬 브라우저에서 가이드 목록 → 기사 → 3개 컬렉션 결과 → 기사로
  돌아오는 링크를 확인했다. canonical, H1 한 개, 16px 본문과 데스크톱
  가로 넘침 없음을 확인했다.
- 390px iframe으로 모바일 배치와 줄바꿈을 확인했다. 실제 휴대폰
  하드웨어 검증은 아니다. 임시 확인 파일은 빌드 전에 삭제했다.
- 새 페이지가 정적으로 빌드됨을 확인했다. CI·Preview 통과 뒤 병합하며
  배포 확인은 별도 실행 원장에 기록한다.

이는 소비자 가이드 게시이며 검색 유입·구매·계약 성과를 입증하지 않는다.
