# Chapter 24 — 모바일 순서 재지정과 사진 배너 퀵링크

### 목표
민호 지정 모바일 순서를 구현한다: 라켓 이미지 쇼케이스(2026 NEW) 먼저 →
인기 TOP 5 → 3분 진단 배너 → 퀵링크. 퀵링크는 사진 위에 페이드를 깔고
텍스트를 얹은 사진 배너로 바꾼다.

### 완료 내용
- **히어로 분해**: 피치(라켓을 읽습니다 + 진단 CTA)를 `HeroPitch` 로 추출.
  데스크톱은 기존처럼 히어로 안에 h1 으로, 모바일은 히어로에서 숨기고
  TOP 5 아래 별도 다크 배너에 일반 텍스트로 렌더 — h1 은 DOM 에 정확히
  하나(데스크톱용)만 존재하고 테스트가 요구하는 문자열은 전부
  hero-carousel.tsx 안에 남는다.
- **모바일 시각 순서** (CSS order, md 미만): 쇼케이스 → TOP 5 → 진단 배너
  → 사진 배너 퀵링크 → 업데이트 → 선수 레일 → 상식 → 스트링 → 파트너.
  DOM/데스크톱 순서는 무변화.
- **퀵링크 사진 배너**: 아이콘 카드 → `rackets/*.png` 촬영 에셋 재사용.
  아래쪽 검정 페이드 + 백색 텍스트, hover 시 미세 스케일(모션 감소 존중).
  비교 = Radical(주황 헤드), 라켓 DNA = Ultra(파랑), 스트링 가이드 =
  Shift(백색 스트링 베드 크롭 — 주제를 사진이 직접 가리킨다).
  첫 시안은 어두운 라켓 3종이라 검정에 묻혔고, 밝은 색 3종으로 교체.
