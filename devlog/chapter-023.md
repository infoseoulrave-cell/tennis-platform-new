# Chapter 23 — 모바일 실기기 라운드: 능력치 표시 · 정렬 알약 · 히어로 중간 배치

### 목표
민호가 아이폰 실기기로 확인하며 보고한 이슈를 당일 처리한다.

### 완료 내용
- **TOP 5 능력치 (PR #7)**: 세로 모드에서 5축 막대가 안 보인다는 리포트.
  노치가 아니라 Ch.20 의 `hidden sm:flex` 가 원인 — 640px 미만에서 막대를
  접었었다. 5축은 정체성이라 접지 않기로 하고, 좁은 화면은 가격을 막대
  아래로 내려 이름 칸을 확보. 범례 문장도 항상 노출.
- **라켓 목록 정렬 알약 (PR #8)**: 정렬 옵션 6개가 줄바꿈·스크롤 없는 flex
  한 줄에 짓눌려 한글이 글자 단위로 꺾이며 세로로 길쭉해졌다.
  `whitespace-nowrap` + 좁은 화면은 개수 텍스트 윗줄·알약 한 줄 가로 스크롤,
  `sm` 이상은 기존 유지.
- **히어로 중간 배치 (PR #9)**: 모바일에서 진단 배너(검은 히어로)가 첫 화면을
  가득 채워 광고처럼 읽힌다는 리포트. md 미만에서만 CSS `order` 로 시각
  순서를 변경 — 인기 TOP 5 → 히어로 → 퀵링크 → 업데이트 → … 순.
  DOM 순서는 데스크톱 기준 그대로라 h1 하나 규칙·SEO 무변화, 데스크톱 무변화.
- **"AI" 단어 제거**: trust-badge "광고 없는 AI 진단" → "광고 없는 진단",
  about "AI 추천" → "맞춤 추천". 사용자 노출 문자열에서 AI 전부 소거.
