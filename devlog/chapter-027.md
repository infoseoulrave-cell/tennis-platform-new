# Chapter 27 — 제휴 제안과 실제 계측 준비

2026-09-13 (KST)

제휴 담당자가 검토할 수 있도록 `/advertise`에 4주 캠페인의 기준 가격(250만 원, VAT 별도), 최대 5개 모델, 제공 범위와 파트너 역할을 명시했다. 방문·매출 보장을 하지 않으며, 광고 형식과 시작일은 계약 전 협의한다. 문의 폼과 운영팀 이메일을 함께 제공한다.

모든 공개 경로의 페이지 방문을 기록하고, 탭 단위 세션과 UTM을 경로 이동 후에도 유지한다. 내부 점검은 `internal`로 구분하고, 일반 방문은 검증되지 않은 `unclassified`로 기록한다. 페이지 및 유입 URL의 쿼리와 fragment는 저장하지 않는다. 이벤트 API는 실제 저장을 기다리며 실패 시 503을 반환한다. 근거 없는 인기 순위 표시는 라켓 둘러보기로 변경했다.

스폰서 이벤트 enum 마이그레이션은 재실행 가능한 형태로 만들었다. 기존 실제 오퍼나 후원 계약을 임의로 생성하지 않았다.

검증: 전체 290개 테스트, 타입 검사, 린트, 프로덕션 빌드 통과. 로컬 `/advertise`의 캠페인 범위와 가격, 내부 `page_view` 저장, 직접 문의 성공 화면 및 DB 저장을 확인했다. 점검용 문의 한 건은 식별자와 이름을 함께 대조해 삭제했으며 영업 실적에 포함하지 않는다. 프로덕션 반영은 PR의 CI와 Vercel Preview 확인 후 진행한다.
