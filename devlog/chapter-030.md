# Chapter 30 — 홈 배너 사진과 출처 정리

2026-09-13 KST.

사용자가 홈 배너에서 라켓이 그래픽과 사진 사이의 어색한 합성처럼 보인다고 지적했다.
기존 히어로는 미검증 생성 라켓 PNG 하나를 확대 배경과 작은 전경에 반복했고,
실제 제품 사진을 가리키는 출처 링크가 그 렌더에 붙어 있었다.

## 변경

- 코트·네트·공을 담은 정적 사진형 배경을 별도 제작했다. 내장 이미지 생성 도구를
  사용했으며 웹에서는 AI 연출 배경임을 표시한다. 배포 WebP는 1536×1024, 약 191KiB다.
- Babolat Pure Aero, HEAD Speed MP, Yonex VCORE의 히어로 제품 사진을 이미 검증된
  로컬 리테일러 JPG로 교체했다. 원래 색상과 제품 형상을 보존하고 흰 사진면에 표시한다.
- 실제 제품 사진, 점수·스펙, 생성 배경의 역할과 출처를 구분했다.
- 라켓 이미지 중복 확대를 없애고 모바일 사진 높이를 제한했다. 세 슬라이드의
  회전·호버·키보드 포커스·모션 감소·후원 표시 조건과 기존 진단 동선은 유지한다.

생성 프롬프트와 이미지 출처 기록은 [hero-imagery.md](../docs/hero-imagery.md)에 있다.

## 검증

로컬 브라우저에서 데스크톱 화면과 390px·320px 폭의 iframe 반응형 화면을 점검했다.
이는 실제 휴대전화 하드웨어 검증이 아니다. 배경과 제품 사진의 로드, 모델별 전환,
사진과 정보의 분리, 출처 표시를 확인했다.

- 기존 전체 테스트 298개 통과.
- 타입 검사, ESLint, 프로덕션 빌드, diff 공백 검사 통과.
- 새 배경과 제품 사진의 로드 및 HEAD 슬라이드 전환·상세 링크 확인.
- PR의 CI와 Vercel Preview 성공 및 운영 반영은 실제 배포 결과를 별도로 확인한다.
