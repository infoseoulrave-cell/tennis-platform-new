# Chapter 32 — 모바일 라켓 필터와 URL 상태 정리

기존 라켓 목록은 브랜드·무게·헤드사이즈·레벨 필터를 데스크톱
사이드바에만 렌더해 1024px 미만에서 사용할 수 없었다. 모바일·태블릿에는
필터 펼치기와 적용 조건 수, 조건 초기화를 제공하고 데스크톱은 사이드바를
유지했다. 선택지는 같은 컴포넌트와 URL 규칙을 사용한다.

## 변경

- 네이티브 details/summary로 키보드 펼침·접힘과 확장 상태를 제공한다.
- 필터 상태를 URL에서 직접 읽고 링크로 갱신한다. 검색·정렬·다른 필터·
  반복 brand 파라미터를 보존하며 범위가 바뀌면 page를 초기화한다.
- 임의 무게/헤드 범위에서는 현재 범위를 그대로 표시해 기존 배열의
  -1 인덱스 접근 오류를 제거한다. 뒤로가기 후 선택 표시도 URL과 일치한다.
- 초기화는 필터와 페이지 번호만 지우고 검색·정렬을 남긴다.
- 데스크톱 긴 사이드바에는 높이 제한과 내부 스크롤을 적용했다.

## 검증

- 신규 회귀 6개 포함 npm test 304/304 통과.
- npm run typecheck, npm run lint, npm run build, git diff --check 통과.
- 독립 코드 리뷰에서 새 P1/P2 없음.
- 인앱 브라우저의 390px iframe에서 키보드로 필터 펼침 → Head 선택 →
  적용 1개 표시 → 접힘 후 70개에서 13개 결과로 변경됨을 확인했다.
  실제 휴대폰 하드웨어 검증은 아니다.
- 데스크톱 Head + 270–290g 조건에서 두 라켓을 표시하고 URL과 선택 표시,
  내부 QA 파라미터 보존 및 가로 넘침 없음을 확인했다.
- 임시 responsive QA 파일은 빌드 전에 삭제했다.

CI와 Preview를 확인한 뒤 병합하고 실제 운영 배포 기록을 별도로 남긴다.
본 변경의 편의성 개선을 실제 구매나 전환율 향상으로 집계하지 않는다.
